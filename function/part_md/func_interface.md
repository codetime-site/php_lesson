# Интерфейсы и абстрактные методы

- для чего нужен Интерфейсы и абстрактные методы ?
   - Интерфейсы и абстрактные методы нужны для создания строгих правил (контрактов) в коде. Они заставляют программиста обязательно написать определенные методы в дочерних классах, гарантируя, что программа не сломается из-за отсутствия нужной функции.

- Их главные задачи:
   - Унификация кода: Все разработчики пишут методы с одинаковыми названиями.
   - Полиморфизм: Позволяют подменять одни объекты другими (например, заменить отправку SMS на Email), не меняя остальной код.- - - 
   - Безопасность: Защищают от архитектурных ошибок на этапе написания кода.

- При объявлении методов в интерфейсах или абстрактных методов в классах фигурные   скобки не ставятся, так как у них нет тела. Вместо них ставится точка с запятой ;:

```php

interface MyInterface {
   public function test(); // Без фигурных скобок

}

```
